`full-cycle` select the implementation depth; `direct` and `OpenSpec` select
the planning mode independently. Direct planning remains the default, and a
promotion trigger changes only the execution path.

artifacts and the current orchestration setting. Direct execution performs the
same essential structural spec-compliance checks without loading the full
subagent pipeline. Delegated execution keeps the complete Stage 4a hand-back
and evidence contract. Closing verification, task completion, delta sync, and
explicit-only review remain unchanged.
