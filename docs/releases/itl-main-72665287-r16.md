## Scope

This downstream policy release restores the upstream separation between
execution depth and planning mode. Code and metadata changes first select
`quick-fix` or `full-cycle`; full-cycle executes directly by default and uses
OpenSpec only when explicitly requested or when formal discovery/agreement
adds value. Promotion triggers retain full-cycle depth without forcing
OpenSpec.

The ITL completion invariant is unchanged: relevant Vanessa coverage and a
fresh successful `/itl-check` after the last change remain mandatory before an
agent reports an installed-project configuration or extension change ready or
done.

## Qualification

policy regressions, overlay reconstruction/idempotence, UTF-8/parser checks,
and Git diff checks. Fork Full and workflow Full/Release gates are
intentionally not run; publication evidence must retain that limitation.
