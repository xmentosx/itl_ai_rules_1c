## Scope

This release repairs managed-file drift classification on Windows. A Git
checkout that changes only LF versus CRLF in strict UTF-8 text no longer
creates false `userModified` markers, and update clears markers left by an
older installer when the current content is provably byte- or EOL-equivalent.
Invalid UTF-8 and binary-looking files remain byte-strict.

Update also removes obsolete manifest entries owned by `legacy` even when
their paths are outside the historical hard-coded client layouts. Clean and
EOL-equivalent legacy files are deleted; genuinely modified files are kept.
All other downstream paths are reconstructed from the qualified r23 content;
the audited upstream commit is unchanged.
